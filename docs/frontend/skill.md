# Skill 管理页 · 设计说明 + HTML

**HTML 路径：** `D:\project\z-torque-community-m1\docs\frontend\skill.html

---

## 1. 页面定位（对齐阶段 6 / 10）

| 能力 | 说明 |
|------|------|
| 列表 | 有权访问的 Skill，区分官方 / 我的 |
| 模式 | **纯指令**（md_instruction）与 **脚本**（md_script） |
| 版本 | 草稿 / 已发布；已发布不可原地改 |
| 操作 | 创建个人、复制官方、编辑草稿、发布、启停 |
| 内容 | 描述、权限、Schema、SKILL.md 预览、脚本清单、关联 Tool |
| 约束 | 前端不执行脚本；不直连 Tool；官方只读须先复制 |

---

## 2. 布局

与 Agent 页一致：**左列表 + 右详情（多 Tab）**。

---

## 3. 左侧列表

| 元素 | 内容 |
|------|------|
| 创建 | 「创建 Skill」 |
| 搜索 | 名称 / 描述 |
| 筛选 | 全部 / 我的 / 官方 / **纯指令** / **脚本** |
| 卡片 | 名称、描述、官方/我的、模式标签、状态、版本号 |

---

## 4. 右侧详情

### 标题区操作

| 状态 | 按钮 |
|------|------|
| 官方 | 复制到我的、查看快照 |
| 我的已发布 | 编辑草稿、发布新版本、停用 |
| 我的草稿 | 继续编辑、发布、删除草稿 |

### Tab 内容

| Tab | 应展示 |
|-----|--------|
| **概览** | name、implementation、allow_scripts、来源路径、系统版本号、required_permissions、input/output schema 摘要；MD-Skill 与 Gateway 说明 |
| **指令与内容** | SKILL.md 正文只读预览（场景 / 执行要求 / 输出要求）；说明指令为不可信输入 |
| **脚本与文件** | scripts/ 已登记文件列表（无运行、无在线 IDE）；网络/目录/超时/密钥等约束只读展示 |
| **关联 Tool** | Tool 名、版本、说明、状态；强调经 SkillGateway |
| **版本** | 版本时间线 + 快照；文件变更生成新草稿、不覆盖已发布 |

---

## 5. 与 MD-Skill / Chat 的关系

- 列表与详情能区分纯指令 / 脚本，便于和 Chat Task 过程对照。
- **无**「在浏览器运行脚本」入口。
- Agent 绑定的是 **SkillVersion**，本页展示被哪些版本引用可后续加，当前以版本与 Tool 关联为主。
