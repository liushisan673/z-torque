# Model 管理页 · 设计说明 + HTML

**HTML 路径：** `D:\project\z-torque-community-m1\docs\frontend\model.html`

---

## 1. 页面定位（对齐阶段 10）

| 能力 | 说明 |
|------|------|
| 层级 | **Provider → Model → Endpoint** |
| 配置 | 名称、接口地址、模型标识、参数 |
| 密钥 | 仅通过 Secret URI /「已配置」展示，**禁止明文** |
| 测试 | 测试连接并展示成功/失败、耗时、摘要错误 |
| 状态 | 可用 / 停用 / 最近错误摘要 |
| 约束 | 调用一律经后端 ModelGateway；前端不直连上游、不存密钥 |

权限：无 `model.manage` 时整页只读或隐藏编辑/测试写操作（演示中按 admin 展示）。

---

## 2. 布局

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏（Model 高亮）                                         │
├────────────────┬─────────────────────────────────────────┤
│ 左侧 ~300px    │ 右侧详情                                  │
│ Provider 分组  │ 标题 + 状态标签 + 测试/编辑/停用            │
│  └ Model 列表  │ Tab：概览 / Endpoint / 密钥 / 连接测试     │
└────────────────┴─────────────────────────────────────────┘
```

---

## 3. 左侧应展示

| 元素 | 内容 |
|------|------|
| 添加 Provider | 入口（管理员） |
| Provider 行 | 名称 + 状态点（绿可用 / 黄告警 / 灰未连接） |
| Model 行 | 模型名、可选「默认」「未连接」等小标签 |
| 选中 | 联动右侧详情 |

---

## 4. 右侧详情

### 标题区

- 面包屑：`Model / {Provider} / {Model}`
- 状态标签：可用 / 需关注 / 不可用；密钥已配置 / 未配置
- 按钮：测试连接、编辑、停用（按权限）

### Tab：概览

- 显示名称、`model_id`、Provider、接口类型（如 OpenAI 兼容）
- 说明、启用状态、是否可供 Agent 选择
- 最近测试结果、延迟、最近错误摘要

### Tab：Endpoint

| 列 | 内容 |
|----|------|
| 名称 | 默认（生产）、备用等 |
| Base URL | 完整地址（可截断） |
| 状态 | 启用·默认 / 停用 |
| 操作 | 编辑、添加 Endpoint |

说明：超时等高级项以后端为准，调用仍走 Gateway。

### Tab：密钥

- 告警：不展示明文；更换走专用流程
- 展示：`已配置` + `secret://••••` 类引用
- 按钮：更换密钥（提交后由后端写 Secret Store）

### Tab：连接测试

- 选择 Endpoint、探测方式（最小 Chat / 模型列表等）
- 「运行测试」→ 成功/失败块：HTTP 状态、耗时、摘要、`trace_id`
- 强调：经 ModelGateway，非浏览器直连

---

## 5. 安全与验收要点

- [ ] 任何接口响应中都不出现 API Key 明文  
- [ ] 测试失败展示可理解错误 + trace，不堆栈、不泄路径  
- [ ] 停用后 Agent 配置侧不可再选（或可选但调用失败由后端拒绝）  
- [ ] 无管理权限用户看不到添加/编辑/更换密钥
