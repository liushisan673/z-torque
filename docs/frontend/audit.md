# Audit 审计页 · 设计说明 + HTML

**HTML 路径：** `D:\project\z-torque-community-m1\docs\frontend\audit.html`

---

## 1. 页面定位（对齐阶段 10）

| 能力 | 说明 |
|------|------|
| 筛选 | 时间、事件类型、执行用户、Agent、Task 等 |
| 事件类型 | 登录、权限判断、Task 状态、模型调用、Skill 执行、配置变更 |
| 列表字段 | 时间、主体、资源、结果、耗时、Trace ID |
| 详情 | 脱敏摘要、关联资源、同 Trace 执行链路 |
| 跳转 | 从事件进入相关 Task / 执行记录（如回 Chat） |
| **禁止** | 关闭审计、修改历史、删除记录（界面无此类入口） |

权限：`audit.read` 看自己相关；`audit.read_all`（admin）看全量。页面顶部提示当前范围。

---

## 2. 布局

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏（Audit 高亮）                                          │
├────────────────────────────────────────────────────────────┤
│ 筛选栏：时间 / 类型 / 用户 / Agent / Task / 结果 · 查询重置   │
│ 范围提示：全量 or 仅我的 · 前端只读说明                      │
├─────────────────────────────────────┬──────────────────────┤
│ 事件表格 + 分页                      │ 详情抽屉（可选）      │
│ 时间·类型·用户·摘要·结果·耗时·Trace │ 基本信息 / 资源 /     │
│                                     │ 脱敏摘要 / 链路       │
└─────────────────────────────────────┴──────────────────────┘
```

---

## 3. 筛选区应展示

| 筛选项 | 说明 |
|--------|------|
| 时间范围 | 近 24h / 7d / 30d / 自定义 |
| 事件类型 | 全部、登录、权限、Task、模型、Skill、配置 |
| 执行用户 | 用户名（admin 可查他人） |
| Agent | 名称或 ID |
| Task ID | 精确关联 |
| 结果 | 全部 / 成功 / 失败 / 拒绝 |
| 查询 / 重置 | 触发列表刷新 |

范围文案示例：`管理员 · 可查看全量审计` 或 `普通用户 · 仅与我相关的记录`。

---

## 4. 表格列

| 列 | 内容 |
|----|------|
| 时间 | 本地可读时间 |
| 类型 | 彩色标签（登录/权限/Task/模型/Skill/配置） |
| 执行用户 | 操作主体 |
| 资源 / 摘要 | 一行摘要，过长省略 |
| 结果 | 成功 / 失败 / 拒绝 |
| 耗时 | 有则显示 |
| Trace ID | 等宽字体，便于复制 |

行点击打开右侧详情；支持分页。

---

## 5. 详情抽屉

| 区块 | 内容 |
|------|------|
| 提示 | 已脱敏；无删除/关闭审计 |
| 基本信息 | 时间、类型、结果、耗时、用户、Trace ID |
| 关联资源 | Agent、Task、Skill、会话；链到 Chat 看 Task、复制 Trace |
| 摘要 | JSON/文本，后端脱敏后的参数与错误摘要 |
| 同 Trace 链路 | 按时间排列的模型 → Skill → Task 等步骤 |

---

## 6. 明确不做

- 删除 / 编辑 / 关闭审计开关  
- 展示密钥、完整原始请求体、未脱敏 PII  
- 替代后端作为审计权威来源
