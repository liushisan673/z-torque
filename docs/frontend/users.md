

## 1. 定位与权限

| 项 | 说明 |
|----|------|
| 谁可进 | 仅 `admin`（需 `user.read` / `user.create` / `user.update` 等） |
| 导航 | 建议放在头像「系统管理」，或顶栏次要入口；可不占六大主业务导航 |
| 不做 | 自助注册、邮箱验证、SSO（社区版文档未要求） |

角色仍建议只有两个系统角色（与先前方案一致）：

- **admin**：全部权限  
- **user**：Chat + 个人资源

## 2. 页面应展示的内容

### 列表

| 列 | 内容 |
|----|------|
| 用户 | 头像字、用户名、显示名 |
| 角色 | admin / user 标签 |
| 状态 | 正常 / 已禁用 / 已锁定（登录失败锁定） |
| 最近登录、创建时间 | |
| 操作 | 编辑、重置密码、禁用/启用、解锁（按状态显示） |

工具栏：搜索用户名、按角色/状态筛选、**创建用户**。

规则提示：

- 至少保留一名可用 admin  
- 不可禁用/删除「最后一个管理员」  
- 操作写审计  

### 侧栏详情

用户名、显示名、角色、状态、ID、创建时间、最近登录、连续失败次数；管理员保护说明。

### 创建 / 编辑弹窗

- 用户名（必填，唯一；编辑时是否可改由后端定）  
- 显示名（可选）  
- 初始密码（仅创建）  
- 角色二选一：user / admin（说明差异）  

### 重置密码弹窗

新密码 + 确认；后端 Argon2id；写审计。

## 3. 与表结构的关系

| 表（你方 / 文档） | 页面用途 |
|------------------|----------|
| 用户表（如 `ai_user` / `zr_user`） | 列表与创建 |
| `ai_role` | 角色选项（admin、user） |
| `ai_role_permission` / `ai_user_role` | 保存时绑定角色；权限不在前端配置 |
| 会话/锁定字段 | 展示锁定、失败次数；解锁清零 |

前端不编辑权限点明细，只选角色。

## 4. 建议 API（与页面按钮对应）

| 方法 | 路径（示例） | 权限 |
|------|----------------|------|
| GET | `/api/z-torque/users` | user.read |
| POST | `/api/z-torque/users` | user.create |
| PATCH | `/api/z-torque/users/{id}` | user.update（角色、显示名、启停） |
| POST | `/api/z-torque/users/{id}/reset-password` | user.update |
| POST | `/api/z-torque/users/{id}/unlock` | user.update |
| GET | `/api/z-torque/roles` | role.read |

全部需 admin；越权返回 `AI_FORBIDDEN`。
