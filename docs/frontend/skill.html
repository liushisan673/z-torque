分析结构化数据并生成摘要，支持区域汇总与异常检测。

◈ MD-Skill 规范（社区版）： 目录 md-skills/<name>/SKILL.md → 解析 YAML front-matter + 正文 → 写入 zr_skill(skill_type=MD_SKILL) + zr_skill_version。 前端不读磁盘，只展示已入库记录。执行走 SkillGateway，无浏览器跑脚本。

params（JSON Schema · 工具入参）

执行前按 schema 校验入参；注册制路径下作为工具入参描述。

脚本 · 受控子进程

正文 · 给模型看的操作手册 不可信输入，不能覆盖系统策略 / PEP

适用场景

  • 分析用户提供的结构化数据（表格、CSV 等）
  • 提炼关键变化、区域对比与异常点

执行步骤与判断规则

  • 先确认数据范围和分析目标
  • 说明关键发现及其依据
  • 不得编造数据中不存在的指标
  • 数据不足时明确说明局限性

输出格式要求

输出结论、关键依据和必要的局限性说明。

ℹ 注册制路径：正文作为该工具的「操作说明」注入工具描述（或按需一次性上下文）； 模型据此调用；params 作入参 schema。 脚本路径（allow_scripts: true）：受控子进程执行，stdout/stderr 回传并截断。

加载与生效（规范）

后端
  1. 启动时扫描 md-skills/；watchdog 监听变更（新增/修改 ≤ 30 秒生效，不重启）
  2. 解析 front-matter → 校验 → 写 zr_skill(skill_type=MD_SKILL) + zr_skill_version
  3. 默认状态 ENABLED；首次启用需管理员一次确认
  4. 绑定到 Agent 版本后，下一轮对话即可被模型看到
