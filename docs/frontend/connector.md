# Connector 管理页 · 设计说明 + HTML

**HTML 路径：** `D:\project\z-torque-community-m1\docs\frontend\connector.html`

---

## 1. 页面定位（对齐阶段 10 / 7）

| 能力 | 说明 |
|------|------|
| 类型 | **REST**、**只读数据库**、**MCP**（stdio / HTTP） |
| 生命周期 | 创建、查看、编辑、启停 |
| 认证 | API Key / Bearer、Basic、管理员允许的匿名 |
| MCP | JSON-RPC 2.0，`tools/list` / `tools/call` |
| 展示 | 连接状态、健康检查、可用能力摘要 |
| 测试 | 测试连接 / 健康检查 |
| 约束 | 库必须只读并限表/查询；凭证仅 Secret URI；前端不直连目标系统 |

权限：`connector.manage` 才能新建/编辑/停用；普通用户只读状态（文档：连接由管理员管理）。

---

## 4. 右侧详情

### 标题区

- 面包屑：`Connector / {类型}`
- 标签：类型、健康/降级/停用、凭证状态
- 按钮：测试连接、编辑、停用（停用后改为启用）

### Tab：概览

- 名称、类型、描述、启用状态、最近检查
- 健康摘要：连通性、延迟、可用操作数

### Tab：连接配置（按类型切换）

| 类型 | 字段要点 |
|------|----------|
| **REST** | Base URL、超时、TLS 校验 |
| **数据库（只读）** | 驱动、主机端口、库名、允许的表、查询限制（仅 SELECT 等） |
| **MCP** | 传输 HTTP/stdio、端点或命令、超时 |

### Tab：认证与密钥

- 模式：Bearer / API Key / Basic / 匿名（需管理员允许）
- 凭证：仅「已配置」+ `secret://••••`，更换凭证按钮
- 明文禁止展示

### Tab：操作 / 能力

表格：操作名、方法或类型、说明、是否已注册为 Tool  

说明：发现 ≠ 授权；注册后经 SkillGateway，前端不直调。

### Tab：健康检查

- 说明由后端按类型探测
- 运行检查 → 成功/失败、耗时、`trace_id`

---

## 5. 安全与验收

- [ ] 无数据库写连接、无无表限制的生产配置  
- [ ] 无密钥/密码明文  
- [ ] 无前端直连 CRM/DB/MCP  
- [ ] 停用后不可被 Skill 调用（后端拒绝）  
- [ ] 无 `connector.manage` 时无编辑入口
