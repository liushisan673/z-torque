以下是几点实际行为差异，这些差异与 README 里的旧示例并不一致：

- **真实请求头**是 `X-Webhook-Timestamp`（秒级）；当前 `.env` 使用 `WEBHOOK_AUTH=bearer`，所以只带 `Authorization: Bearer <WEBHOOK_SECRET>`，不带 `X-Webhook-Signature`。改回 hmac 时才带 `X-Webhook-Signature: sha256=...`，签名内容为 `${timestamp}.${rawBody}`。
- **`conversation_id` 实际等于 `peer_id`**，并非 README 写的 `accountId:peerId`：入参 `req.conversationId` 来自 `from_user_id`（[impl.ts](file:///d:/project/weixin/src/channel/impl.ts#L175-L196)），审计日志也印证了这一点。
- `message.timestamp` 是 Bridge **收到消息时**的毫秒时间戳，不是微信侧的 `create_time_ms`。
- `event_id` 格式固定为 `${messageId}-${Date.now()}`，每次投递都会变，幂等请优先用 `message.message_id`。
- 图片 `mimeType` 固定是 `"image/*"`；媒体文件名形如 `{ms时间戳}-{8位hex}.jpg`，位于容器 `/tmp/weixin-agent/media/<子目录>/`。
