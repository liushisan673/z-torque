## 1. 技术选型与安装

```bash
npm install antd @ant-design/x @ant-design/icons
# 如果用 React 19，确认 antd 版本兼容即可
```

建议：
- React 18/19
- Ant Design 5.x 或 6.x
- `@ant-design/x`（AI 对话专用组件）

## 2. 全局主题（关键：决定高级感）

在根组件用 `ConfigProvider` 包住，Token 要克制：

```tsx
import { ConfigProvider, theme } from 'antd';

const premiumTheme = {
  token: {
    colorPrimary: '#2563eb',          // 主色，不要太艳
    colorBgBase: '#ffffff',
    colorBgLayout: '#f8fafc',         // 整体背景极浅灰
    colorBorder: '#e2e8f0',
    colorText: '#0f172a',
    colorTextSecondary: '#64748b',
    colorTextTertiary: '#94a3b8',

    borderRadius: 8,                  // 整体偏小圆角
    borderRadiusLG: 10,
    borderRadiusSM: 6,

    fontSize: 14,
    fontFamily: `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`,

    // 阴影尽量弱
    boxShadow: '0 1px 2px rgba(15, 23, 42, 0.04)',
    boxShadowSecondary: '0 1px 3px rgba(15, 23, 42, 0.06)',
  },
  components: {
    Layout: {
      headerBg: '#ffffff',
      siderBg: '#ffffff',
      bodyBg: '#f8fafc',
    },
    Button: {
      borderRadius: 8,
    },
  },
};

function App() {
  return (
    <ConfigProvider theme={premiumTheme}>
      {/* 你的路由 / 页面 */}
    </ConfigProvider>
  );
}
```

## 5. 实现时必须注意的细节（决定「高级」还是「普通」）

| 项目 | 要求 |
|------|------|
| 消息最大宽度 | **680–720px**，居中，左右必须有大量留白 |
| 消息间距 | 上下至少 28–32px |
| 气泡边框 | 助手消息用极细边框，**不要重阴影** |
| 过程展示 | 优先用 `ThoughtChain`，默认给人「已折叠」的感觉，最终答案先出现 |
| 输入区 | 用官方 `Sender`，圆角 12–14px，阴影极轻 |
| 侧边栏 | 宽度 260–280px，会话项圆角 8px，激活态用浅主色背景 |
| 顶栏高度 | 52–56px，不要太高 |
| 字体 | 系统字体栈即可，字重用 400/500/600，少用 700 |

## 7. 下一步建议顺序

1. 先把 `ConfigProvider` + Token 配好  
2. 搭出 Layout（顶栏 + 侧栏 + 主区）  
3. 用 `Bubble` 把消息流跑通  
4. 加上 `ThoughtChain`（过程）  
5. 接入 `Sender`  
6. 最后微调间距和激活态颜色

按这个做出来的效果，会明显比之前那版更干净、更接近现在主流 AI 产品的气质。
