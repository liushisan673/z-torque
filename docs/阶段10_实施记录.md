## API 契约对接

前端严格对接后端实际路由，未创建第三套协议：

- Chat：`POST /api/z-torque/chat`（带 `Idempotency-Key`），按 `response_type` 区分 `CHAT`/`TASK`；`TASK` 时连接 `GET /tasks/{id}/stream`。
- Task SSE：处理 `task.snapshot` 与 `TASK_*` 事件，按 `id` 去重，映射到解释性文案。
- 人工确认：Task 进入 `WAITING_HUMAN` 时查询 `/confirmations` 匹配待确认项，支持批准/拒绝。
- 文件：`POST /files` 上传后，`content_parts` 传 `[{file_id}]` 参与 Chat。
- 管理页：Agent / Skill-Tool / Model / Connector / Audit 均对接后端真实接口；密钥仅回显 `secret_configured`。
