## 一、形态总定义（一句话）

> **一份开源内核 + 官方专有插件 + 两档授权（社区版 / 企业版）+ 三套装配预设；自带控制台为主、可嵌入宿主；API 优先、前端可替换；独立可售，也可与 ZSoftYM 矩阵产品组合，可接任意第三方系统。**

---

## 二、已确认决定（D1–D9）

| # | 决定项 | 定论 | 影响面 |
|:--|:---|:---|:---|
| **D1** | **产品身份** | **独立产品优先**：可单独售卖 / 部署 / 验收；**不以任何上游产品为成立条件**；可与 Z-Compiler / TruthLayer / Object Runtime / OAG（方法）**可选组合**；可接任意第三方系统（ERP / OA / CRM / MES / 自研） | 规划文档 §0.1（已写） |
| **D2** | **商业分层** | **两档授权**：**社区版**（免费开源）/ **企业版**（付费）。**授权是商业概念，装配是技术概念，两者解耦** | 取代原「lite / standard / enterprise」三档 |
| **D3** | **装配预设** | 技术上有**三套**：`standalone`（单容器或单二进制）/ `multi-container`（3–5 容器）/ `k8s`（多命名空间）。社区版＝`standalone`；企业版三套任选 | 取代原「profile」三档表述 |
| **D4** | **界面形态** | **自带控制台为主、嵌入宿主为辅**：社区版轻控制台（Agent / Skill / 模型 / 会话 / 连接器 / 审计 六页）；企业版完整控制台；**同时保留"仅出 API、宿主自行渲染"模式**（银行项目那种） | 修订 `交互.md` 的"只出接口"定位 |
| **D5** | **开源形态** | 内核 **AGPL-3.0 + 商业双许可**（与 TruthLayer 同线）；**官方插件专有**（签名离线 license，实例指纹 + 到期，**不回连服务器**）；**收费卡在「合规 / 连接 / 规模」三处，不卡功能** | 讨论稿 §11 |
| **D6** | **技术内核** | **同一内核**（读法 A）：六件不变量 + **21 个 Port**（见 `Z-Torque_内核契约_v1.md`）+ 三种可装卸单元**共用**；**企业版的能力面 / 数据模型 / 部署重新设计**，但内核与 Port 契约**不重设计** | 内核契约 v1 一页纸；企业版单独立项 |
| **D7** | **旧设计处置** | 阶段 0–11（中国银行项目）**降级为参考素材**：只看机制（Outbox、AIP、审批挂起恢复、混合检索…），**不作权威、不进 `SOURCE_OF_TRUTH` 权威层** | 防团队误用为产品基线 |
| **D8** | **命名** | ✅ **已定：`Z-Torque`（中文「极矩」）** —— 姊妹词架构（非互译）：中文管客户与销售，英文管代码仓库 / 开源 / 文档；物理上同族（torque = 力矩）；与 Z-Compiler / Z-Aligner / Z-Sheet 成体系 | 见 §六 定名记录 |
| **D9** | **前后端关系** | **API 四个面**（控制 / 实时 / 数据 / 内部）；前端可整体替换；**大文件与媒体走预签名直传，不进主 API**；内部面公网不可达 | API 面文档 |

## 三、术语表（新旧对照，后续文档按新术语书写）

| 新术语 | 对应旧术语 | 说明 |
|:---|:---|:---|
| **社区版 Community** | lite | 免费开源；`standalone` 装配；自带轻控制台；单租户；零外部中间件 |
| **企业版 Enterprise** | standard + enterprise | 付费；三套装配任选；含合规 / 连接 / 规模类官方插件；多租户、SSO、沙箱、A2A 网关 |
| **装配预设 Preset** | profile（三档） | `standalone` / `multi-container` / `k8s`，纯技术概念 |
| **内核 Kernel** | — | 六件不变量 + Port 目录 v1 + 装配三层（Profile/Module/Plugin） |
| **官方插件 Official Plugin** | — | 专有许可，付费解锁 |
| **第三方插件** | — | 暂不开放（见 §四-2） |
